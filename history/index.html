History

The original Bongo project ran from 2007 to 2010. It was written in C and Python and continued Hula, a mail and calendar project led by Novell. These pages are the project's documentation and wiki from that time, kept as they were written. The current Bongo is a reimplementation in Go; see the documentation for it.
