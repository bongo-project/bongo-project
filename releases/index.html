Releases

Release notes for the Go reimplementation of Bongo, newest first. Each version links to its GitHub release, where the Linux amd64 and arm64 zips are published. Container images are published at ghcr.io/bongo-project/bongo.

Versions 0.1 to 0.6 of the original C project (2007-2010) have their own release notes under History. The version numbers below belong to the Go project.
